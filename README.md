# Unified Common Vendor Blobs for Realme SM7125 (Atoll)

This repository contains the common proprietary vendor blobs for Qualcomm Snapdragon 720G (SM7125 / Atoll) Realme devices running AOSP / LineageOS-based custom ROMs.

## Supported Devices

- **Realme 6 Pro** (`RMX2061`)
- **Realme 7 Pro** (`RMX2170`)
- **Realme 8 Pro** (`RMX3081`)
